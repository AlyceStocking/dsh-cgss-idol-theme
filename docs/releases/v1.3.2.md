# v1.3.2 — 偶像查询与星标收藏

## 更新

- Web 与 Windows 桌宠设置统一使用一个可搜索的偶像下拉框，移除重复的搜索栏与选择栏。
- 用空心五角星表示未收藏，橙色实心五角星表示已收藏，可再次点击取消。
- 下拉列表中的收藏角色带橙色星标并排在前面；收藏组和普通组内部保持角色目录顺序，搜索仍按姓名/罗马字筛选。
- 收藏存入各端本地存储，重开仍保留。Web 与桌宠收藏独立，不通过 Host 偏好 RPC 同步。
- 支持键盘操作、中文输入法、无结果提示与失焦关闭，保留待收录角色的禁用状态。
- 修复查询期间 Web 设置面板因闲置计时而收起的问题。

## 更新安装

```sh
dsh plugin --profile web add dsh-cgss-idol-theme@1.3.2
# 或使用 DSH Desktop 自带 CLI 更新 desktop profile
dsh plugin --profile desktop add dsh-cgss-idol-theme@1.3.2
```

本次继续发布轻量 npm 包，不含 Electron 二进制；已有 44.5.1 运行时无需重新下载。更新后重启对应的 DSH 服务/桌面应用及 Host。没有自动修改当前安装的 profile 或用户偏好。
