# v1.3.0 — CGSS multi-idol theme

This release integrates the multi-character development history into the original Yukimi theme repository, now named **dsh-cgss-idol-theme**.

## Included

- 190 listed idols, 188 selectable; character colors, backgrounds, outfits and text dialogue.
- Background-only and immersive reading modes.
- Windows x64 desktop companion, independent settings window and session notices.
- Complete prebuilt package including Electron 44.5.1; no build required for this archive.
- Corrected bilingual documentation and runtime coverage statistics.

## Installation and migration

Disable and remove installed `dsh-yukimi-theme` / `dsh-idol-theme` packages first. Do not enable old and new themes together. Existing `idol-desktop` preferences remain supported; the older `yukimi-desktop` directory is not automatically migrated.

Using DSH Desktop's own CLI:

```powershell
dsh plugin --profile desktop add "https://github.com/AlyceStocking/dsh-cgss-idol-theme/releases/download/v1.3.0/dsh-cgss-idol-theme-1.3.0.tgz"
```

For ordinary Web usage, replace `desktop` with `web`, or install the smaller GitHub source package (without the bundled Windows runtime). Check both the package switch and internal `cgss-idol-theme` entry, then fully restart DSH and its Host.

The attached `SHA256SUMS.txt` records the complete archive checksum. Existing v1.2.0 assets are retained and are not overwritten.

## Validation and limits

120 automated tests, syntax/generated-data checks, Windows packaging and complete-archive validation passed. No new live DSH GUI installation/visual acceptance was performed for this release. macOS/Linux do not launch the Windows helper.

Images are referenced online; text translations and metadata are included. Code licensing does not grant rights to the game artwork, original dialogue or translations; see the repository README for attribution and limitations.

The GitHub archive is the supported installation source for this release. npm publication is being attempted separately; do not assume an npm package is available until confirmed.
